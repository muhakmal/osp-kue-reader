Membedah Project PembacaKUE

Sekarang kita tahu teorinya, mari kita lihat bagaimana teknologi ini diterapkan dalam kode pada project aplikasi Cek Saldo E-Toll.

1. Perangkat Pembaca (Reader / Initiator)

Dalam project ini, HP Android bertindak sebagai Reader. Aplikasi Android menggunakan Android NFC API untuk mengakses perangkat keras antena NFC di HP.

Kelas utama yang digunakan di Android adalah NfcAdapter dan kelas-kelas teknologi seperti IsoDep atau NfcA.

Tugas utama HP di aplikasi ini adalah:

  • Mendeteksi saat ada kartu ditempelkan (Intent Action ACTION_TECH_DISCOVERED).
  • Mengirim perintah baca (Transceive APDU) ke kartu.
  • Menerjemahkan data Hexadecimal balasan menjadi Rupiah (Rp).

🤖

Android NFC API

val nfcAdapter = NfcAdapter.getDefaultAdapter(context)
val isoDep = IsoDep.get(tag)
isoDep.connect()
// Kirim perintah (Transceive)
val response = isoDep.transceive(apduCommand)

2. Kartu Target (Tag)

Kartu E-Money/KMT yang dibaca merupakan Smart Card (Kartu Pintar). Berbeda dengan kartu memori biasa, kartu pintar ini memiliki CPU mini (mikrokontroler) dan sistem operasinya sendiri (biasanya Java Card OS).

Kartu ini akan menerima perintah dari HP, memprosesnya dengan keamanannya sendiri (misal mengecek PIN atau kunci enkripsi), dan baru memberikan saldo jika HP mengirim perintah yang benar.

💳

Smart Card ISO 14443

Punya chip kecil untuk memproses data keamanan dan menyimpan file saldo (EF/DF).
